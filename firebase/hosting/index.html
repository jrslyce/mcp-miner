Safety first

No private Codex content is needed to play.

MCP Miner turns abstract work events into game math. The plugin does not need OpenAI credentials, prompts, source code, file paths, repo names, terminal output, browser content, or transcripts.

How to play

Mine while you work, then spend what you earn.

01

Install in Codex

Copy the prompt for your operating system into Codex. The installer registers the local Go plugin and prepares the hook trust flow.

02

Use Codex normally

After restart and hook trust, supported work events become abstract score receipts. Those receipts mine Chonks and materials.

03

Spend what you earn

Use MCP Miner tools to refine materials, complete orders, buy upgrades, build base modules, and unlock equipment.

04

Sync if you want

Link a portal account to see your cloud profile, devices, history, cosmetics, and raw sync receipts.

What data is used

Small receipts in, game progress out.

Used for gameplay

  • Abstract event type and category
  • Server-calculated score and checksum
  • Sequence numbers for conflict detection
  • Aggregated progress, inventory, orders, and upgrades

Not collected for gameplay

  • Prompts, chat transcripts, or source code
  • File paths, repo names, or terminal output
  • Browser contents or OpenAI account credentials
  • Raw private work artifacts

Install

Paste one prompt into Codex to install MCP Miner.

MCP Miner now runs through a compiled Go plugin. Normal installs do not need Ruby, Node, or Firebase tools. If the checked-out plugin binary is missing, the installer can rebuild it with Go.

Mac Apple Silicon

Install MCP Miner on this Apple Silicon Mac. Clone https://github.com/jrslyce/mcp-miner into ~/Code/mcp-miner if needed, then from the repo root make sure the Go plugin binary exists. If plugins/mcp-miner/bin/mcp-miner is missing, run go run ./cmd/mcp-miner build-plugin. Then run sh scripts/install_codex_plugin.sh. Do not use Ruby. After installation, tell me to restart Codex, trust all 6 MCP Miner hooks, and verify with @mcp-miner status.

Codex commands

Play from any Codex project where the plugin is enabled.

Check progress

  • @mcp-miner status
  • @mcp-miner latest report
  • @mcp-miner show my inventory and active orders
  • @mcp-miner show asteroid, milestone, and sync status

Spend and progress

  • @mcp-miner fulfill any ready orders
  • @mcp-miner refine useful materials you recommend
  • @mcp-miner show affordable upgrades and base modules
  • @mcp-miner buy the best affordable upgrade or equipment path

Portal and sync

  • @mcp-miner open dashboard
  • @mcp-miner start account link
  • @mcp-miner complete account link
  • @mcp-miner sync cloud

Should I make a new Codex project?

You can earn passively inside normal coding projects after the plugin and hooks are trusted. A separate Codex project named something like MCP Miner Control Center is useful for game management, account linking, store decisions, and automation setup without mixing those turns into product work.

Automation idea

If your Codex app supports automations, copy this prompt to create a recurring maintenance loop.

Create a recurring MCP Miner automation. On each run, check MCP Miner status, inventory, active orders, store catalog, upgrades, base modules, and sync status. Refine useful materials, fulfill ready orders, complete available weekly contracts, and buy the best affordable upgrades, base modules, machines, or equipment path. Prefer progression unlocks before cosmetics. Sync cloud afterward if linked. Report only the game actions taken and current game totals; do not include prompts, code, file paths, repo names, terminal output, browser content, or transcripts.
